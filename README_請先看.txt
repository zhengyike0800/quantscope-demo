QuantScope AI iPhone 測試版（繁體中文）

本壓縮檔內檔案須上傳到 HTTPS 靜態網站主機後，Safari 才能正常加入主畫面。

建議：
1. 在 iPhone Safari 登入 GitHub，建立 public 的 quantscope-demo 儲存庫。
2. 把解壓縮後的 index.html、manifest.json、sw.js、三張 icon 圖片逐一上傳到儲存庫根目錄。
3. 到 Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。
4. GitHub Pages 發布成功後，Safari 開啟 https://你的帳號.github.io/quantscope-demo/。
5. Safari 分享 > 加入主畫面。

這版僅供介面展示：價格、圖表、分析全部是假資料，沒有連接會員系統、金流或真正行情；不要輸入真實密碼。
GitHub 的 public 儲存庫任何人都能檢視，請不要上傳會員資料、API 密鑰或密碼。
